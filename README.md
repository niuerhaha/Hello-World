
## 一、实验目的

熟悉 Android Studio，学会创建并运行一个简单的 Android 项目。

## 二、实验环境

- Windows
- Android Studio
- Kotlin
- Pixel 7 Pro 模拟器（API 31）

## 三、实验内容和步骤

1. 安装 Android Studio，并安装需要的 Android SDK。
2. 打开 Android Studio，新建一个空白 Android 项目。
3. 等待 Gradle 同步完成，查看项目文件。
4. 启动 Pixel 7 Pro 模拟器，点击运行按钮。
5. 查看 `AndroidManifest.xml`，确认 `MainActivity` 是程序的启动页面。
6. 把项目提交并同步到 GitHub 


## 四、实验结果

项目运行成功，模拟器中显示了 `Hello Android!`，说明项目创建、编译和安装都正常。
